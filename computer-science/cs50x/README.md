# CS50x — Introduction to Computer Science

**Institution:** Harvard University / HarvardX  
**Completed:** 2026  
**Status:** Completed

## Overview

CS50x is Harvard University's introduction to computer science and the intellectual foundations of programming.

The course provided hands-on experience solving computational problems and progressed from programming in C to Python, SQL, and web development.

## Topics Covered

- Computational thinking and problem solving
- C
- Arrays
- Algorithms
- Memory and pointers
- Data structures
- Python
- SQL and relational databases
- HTML, CSS, and JavaScript
- Flask
